# Expense Tracker App

A responsive expense tracker built with vanilla HTML, CSS, and JavaScript.

## Features

- Add income and expense transactions with a description and amount
- View a transaction history with color-coded income and expense items
- Delete individual transactions
- Automatically calculate total income, total expenses, and balance
- Persist transactions in `localStorage`
- Filter the history by all transactions, income only, or expenses only
- Display each transaction with the date it was created
- Show a simple bar chart comparing income and expenses
- Responsive layout for desktop and mobile screens

## Project Structure

```text
expense-tracker/
├── index.html
├── script.js
└── styles/
    └── style.css
```

## How To Use

1. Open `index.html` in your browser.
2. Enter a description and amount.
3. Use a positive amount for income and a negative amount for expense.
4. Submit the form to save the transaction locally in your browser.
